予想信頼度

TIER2 中信頼（最高49pt / 1-3位が同点49pt / 13頭）

  • 平場のためTIER1は使わない（情報制約ルール）。
  • 上位6頭（46〜49pt）と7位以下（≤39pt）の間に明確な段差がある一方、上位3頭が同点で並びが読めない。
  • レースの位置づけ判定は「予算をかけてよいレース（A評価）」だが、1〜2位の点差ゼロ＝混戦警告が1件立っている。よって◎1頭に全券種を寄せない構造にする。

コース特性（新潟芝2200m＝内回り）

  • 新潟の2200mは外回りではなく内回り。直線は358.7mで、日本最長659mの外回りとは別物。
  • 実測プロファイル：前が止まりにくさは「中」、後方から届いた馬の割合は9.8%。先行の有利枠は内。
  • 直近5年の新潟芝2200m（51レース・3着内153頭）の実測：
  • 4コーナー位置 前37%目より前=52% / 中32% / 後16% → 先行〜好位が圧倒的に有利
  • 人気帯 1-3人気=54% / 4-6人気=21% / 7-9人気=18% / 10人気以下=8%
  • 高低差ほぼ平坦。スタミナよりも「楽なポジションを取り、平坦の短い直線で押し切る」型が向く。

馬場状態

  • 想定：稍重〜重（雨主体）。前日夜からの雨、当日も降水確率50%・朝晩雨・所により雷を伴い激しく降る予報。不良までの振れも想定。
  • netkeiba出馬表の事前表示も 天候:曇／馬場:稍 で、道悪前提と整合。
  • 2週前（7/26）の新潟は芝が不良まで悪化した実績があり（芝2000mの勝ち時計2:03.9＝良日より大幅にタフ）、雨量次第で同水準まで行きうる。
  • 過去5年の新潟芝2200m 平均勝ち時計：良 2:13.5 / 稍重 2:16.2 / 重 2:15.7。稍重で約+2.7秒かかる。
  • 道悪の扱いは「守り」限定：道悪血統だけを根拠に格上げ・軸差し替えはしない。加点に使えるのは実際に道悪で好走した実績がある馬だけ。良馬場前提の高速時計評価は無効化する。
  • 道悪＋内回り2200 → 内・前有利へさらにシフト。切れ味一本の差し馬は目減りする。
  • ただし道悪では「後方差しを消す」判定の精度も落ちるため、後方脚質でも末脚が最上位級の馬は1頭だけ3着候補に残す。

展開予測

メインシナリオ（ミドル〜ややスロー・前残り）

明確な逃げ宣言型が少ない構成。新潟で実際に逃げて勝ち negative がある ⑩スイートオレンジ がハナ、②ベルウッドクレド（新馬勝ちは2番手追走）と ⑫ティラーノ が続く形。⑦ウィロークリーク・⑥ディアアズール・⑪リアライズルミナス が好位。
道悪で時計がかかり、内回りで息を入れられるため隊列が縦長になりにくい。恩恵＝好位で流れに乗れる⑦⑪⑥⑩。不利＝後方待機の⑨⑤①。

サブシナリオ（雨量増→重〜不良の消耗戦）

時計がさらにかかり、前が失速する余地が出る。恩恵＝末脚の絶対値が高い⑨モウエエデショー・⑧ムーンストラック。ただし新潟内回りは後方勢の3着内が9.8%しかないため、届いても3着までの想定にとどめる。
