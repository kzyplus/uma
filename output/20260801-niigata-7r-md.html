予想信頼度

TIER2 中信頼（最高50pt / 1-2位点差3pt / 15頭）

  • 平場モードのため TIER1 は出さない方針。
  • 加えて本命は当該コースを一度も走っていないこと、機械モデルの2〜3位の分離度が「団子」＝上位の序列信頼が低いこと、過去8回の柳都ステークスがすべて良馬場開催で今年が初の道悪であることから、TIER2に据え置く。

コース特性（新潟ダート1800m）

  • 1周1472m・直線353mの左回り小回り。前残りが非常に強いコース（過去実測で先行圏の好走率46.0%に対し後方は4.5%）。
  • 特別戦（3勝クラス級）の3着内馬の4コーナー位置は 良で前66%/中団27%/後方7%、道悪でも前54%/中団39%/後方7.5%。
  • → 道悪になっても「差しが届く」わけではない。恩恵を受けるのは後方勢ではなく中団。後方勢は良・道悪ともに約7%で死んでいる。
  • 枠は1枠だけが極端に薄い（道悪の3着内93頭中わずか2頭＝2.2%）。2〜8枠はほぼフラットで、外枠がやや優勢。
  • 勝ち時計の目安（同条件2021〜2026）: 良 1:52.3 / 稍重 1:52.4 / 重 1:51.4 / 不良 1:50.3。
    → 「ダートの道悪は時計が速い」は重・不良で成立し、稍重は良とほぼ同じ。稍重止まりなら時計短縮を期待しない。

馬場状態

  • 馬場状態：稍重〜重を想定（雷雨なら不良まで）
  • 当日の天気: くもり・朝晩雨／雨主体で午後一時曇。降水確率50%。前日夜のはじめ頃にも雨（所により雷を伴い激しく降る）。
  • 本予想は最初から「稍重〜重」を基準に採点している（良前提＋後付けではない）。
  • 前開催週（7/25 稍重・7/26 不良）のダートは勝ち馬の4角通過が全レース1〜3番手。悪化するほど前が止まらなくなった。
  • 良/稍重/重・不良の3コンティンジェンシーは tmp/20260801-niigata-7r-track-bias.md に、削除・追加する買い目まで具体化して記載。

過去傾向（柳都ステークス 過去8年・新潟ダ1800で条件固定）

  • 1〜3番人気の3着内占有率 45.8%、8番人気以下の3着内率 50.0%、11番人気以下でも 37.5%。
  • 過去7年中4年で8番人気以下が3着以内に突っ込んでいる（2024=15人気2着 / 2022=14人気2着 / 2021=14人気1着 / 2020=10人気3着）。
  • レース性質の見出し判定は【中程度】だが、「8番人気以下の3着内率50%以上」という荒れ度ゲートにちょうど該当するため、買い目は荒れ側の構え（上位印BOX＋本命抜きの組合せを別建て）に切り替える。
  • 場・頭数・天候・種別から算出する実データ荒れスコアも 1.0＝【中】（15頭立てが加点、雨が減点）。
  • 前年結果: 2025年 1着タクシンイメル(6人気) / 2着デコラシオン(2人気) / 3着ゴールドアローン(5人気)。
  • 注意: 過去8回はすべて良馬場開催。今年は初の道悪のため、上記傾向の再現性は不確実。

展開予測

逃げ候補: ⑤アデランテ（過去5走の4角平均位置0.12＝最前）、①ベルダイナフェロー（同0.27）。
先行: ⑪レイバックスピン（0.17）、⑥ペンナヴェローチェ（0.32）、⑫クロニクル（0.33）、③エイブラムス（0.35）、⑨ブルータス（0.40）、⑭ショウサンジョージ（0.44）。
中団: ②アラレタバシル（0.46）、⑮オレデイイノカ（0.46）、⑬カフェニクス（0.53）。
後方: ④サンセットブライト（0.68）、⑩フームスムート（0.70）、⑦ゲンパチムサシ（0.79）、⑧ラフエイジアン（0.80）。

  • メインシナリオ（ミドル〜ややハイ）: ⑤アデランテと①ベルダイナフェローがハナを主張して先手争いが起きる。両馬とも本来はダート1400〜1600の逃げ馬で、1800では持たない可能性が高い（⑤は3勝クラス初戦で逃げて4.8秒差、新潟ダ1800の不良では7.2秒差の大敗）。
    → 恩恵を受けるのは「逃げ2頭の直後を取れる先行勢」＝⑪レイバックスピン・⑥ペンナヴェローチェ・⑫クロニクル・⑭ショウサンジョージ・⑨ブルータス。
    → 不利なのは後方勢。道悪でも後方の3着内率は7%程度しかない。
  • サブシナリオ（スロー）: 逃げ2頭が譲り合った場合は完全な前残り。この場合も上の先行勢がそのまま残る形で、結論は変わらない。
  • 馬場が重・不良まで悪化すると脚抜きが良くなり、先行勢がさらに止まらなくなる（前週7/26の不良ダート4鞍はすべて1〜3番手が勝利）。この場合は当該コースの実走時計を持つ⑪レイバックスピン・⑭ショウサンジョージの比重を上げる。

全頭12項目採点

◎ ⑥ペンナヴェローチェ（4枠6番）50pt

適正体重: 496〜506kg / 前走496kg（-2kg） / 直近10走の増減は±8kg以内で安定
初体験: 初・新潟ダート1800m（左回りの中京では3着あり）

項目 点数 評価理由
1.過去実績 4/5 3勝クラス直近10走で2着4回・3着4回。着差はすべて0.0〜0.4秒。ただし3勝クラスでは未勝利（勝ち切れないタイプ）
2.レースレベル 5/5 京都・阪神・中京の3勝クラスという層の厚い舞台で連対を続けている
3.血統 4/5 キズナ×エンパイアメーカー。産駒はダート中距離向きで、道悪でも成績が落ちない（むしろ微増）
4.コース適性 4/5 新潟ダート1800は初。ただし同じ規模の小回りダート1800前後で19走・3着内79%（連対47%）は出走馬中で断然トップ
5.輸送適性 3/5 栗東から新潟への長距離輸送。近走は関西圏中心で遠征実績は薄い
6.休み明け 3/5 中9週（63日）。使い詰めからの一息でリフレッシュ効果は見込めるが特別な実績はない
7.脚質と展開 5/5 好位先行型。前残りが非常に強いこのコースで、逃げ2頭の直後という最良のポジションを取れる
8.枠順 4/5 4枠6番。極端に不利な1枠を回避し、内過ぎず外過ぎない好位置
9.騎手 5/5 戸崎圭太。新潟のダートマイル帯で3年複勝率44.7%＝57人中の上位25%（ほぼ最上位）
10.調教 5/5 7/23ウッド 6F80.9秒-4F51.4秒-終い11.4秒のトップ級。21日間13本と乗り込みも十分
11.馬体 4/5 500kg前後で安定。前走比±5kg超の変動なし
12.厩舎 3/5 須貝厩舎は今年の勝率が例年比-7.0ptで不振。ただし遠征でトップジョッキーを配置しており勝負度は高い
補正 +1 道悪への適性を実走で裏付け（稍重で3着×2）。血統だけの道悪加点はしない方針だが、実走の裏付けがあるので加点
合計 50点 S評価

良い点
- 能力・完成度・状態のすべてが出走馬中トップ。着順に表れない実力（直近1年の僅差負けの蓄積）を測る指標で14ptと断然の1位（2位タイの②⑪が6pt＝2.3倍差）。機械学習モデルの3着内確率も54.0%で2位の1.6倍。
- 同じ規模の小回りダート1800前後で19走して3着内が15回（79%）。舞台適性は数字で裏付けられている。
- 追い切りは終い11.4秒のトップ級。新潟のダートマイル帯で最も成績の良い騎手を配置。

不安材料
- 3勝クラスで15戦して勝ち星なし（2着4回・3着4回）。勝ち切る形は作りにくい。
- 新潟ダート1800を一度も走っていない。前週の同コース振り返りで「馬場が悪化するほど、当該コースの実走時計を持つ馬を優先すべき」という教訓が出ており、重・不良まで悪化した場合はこの弱点が効く。
- ハンデ57.0kgのトップハンデ。厩舎は今年不振。
- 主戦が固定されず騎手が入れ替わり続けている（川田・ルメール・岩田望来・団野が入れ替わり）。ただしこれは「乗り替わりの見限り」ではなく、有力騎手を都度確保している形。

期待点
- 12項目採点1位・機械モデル1位・実力指標1位が同一馬に収束した。ただし収束したから軸を偏重するのではなく、荒れ度ゲートに従って予算は分散する。

参考（本命の位置づけ）: 12項目1位＝実力指標No.1＝⑥（14pt）で同一馬のため、「本命と実力No.1が別馬のときの頭固定保険」は発動しない。
