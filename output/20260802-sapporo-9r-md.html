コース特性（札幌ダ1000）

  • 前残り度＝「強」。後方追込勢の3着内率は 6.0%（コースカルテ実測 2015-2025）。習慣的に後ろから行く馬を軸にしない。
  • ペース感＝「ハイで差し」。実ペースが速くなると後方の3着内率が 5.6%→7.8% に上がる。差しが"届きうる"ようになるだけで、依然として前が有利。
  • 先行勢は外枠有利（ダート短距離の定石。ゲートを出して砂被りを避けられる）。
  • 直線は短く、положение＝前半のポジション取りがほぼすべてを決める一本調子の短距離戦。

展開予測

メインシナリオ（ハイペース・確率高）

  • ハナを主張するのが ⑦ララアヴリル（4角平均位置0.12＝メンバー最前）・③エコロレバン（0.25）・②デアプリームス（0.20） の3頭。
  • 番手を取りに行くのが ①ヒットミー（0.33）・⑫ビーマックス（0.34）・⑧アイアムイチバン（0.35）。
  • 1000mの一本調子戦に 前々を主張する馬が6頭。前半3F争いは締まり、ハイペースになる公算が大きい。
  • 恩恵：中団の差し勢（⑤パールフロント・⑩クインズシフォン・⑨サベージラヴ）。札幌ダ1000は「ハイになるほど後ろが届く」コース。
  • 不利：逃げ一手の馬（⑦・③）。競り合ってしまうと自分の形を作れない。③は前走まさにそれで包まれて12着。

サブシナリオ（隊列がすんなり決まる・スローめ）

  • ⑦が単騎でハナを取り、②③が控える形になれば 前残り極端化。
  • 恩恵：⑦ララアヴリル・①ヒットミー・⑫ビーマックス（前で立ち回れる組）。
  • 不利：⑩クインズシフォン（後ろからの一手になり脚を余す）。

◎ ⑤パールフロント（5枠5番）55.2pt

適正体重: 532-542kg（好走時）/ 前走538kg（+4）/ 大型で安定・馬体面の不安なし
初体験: なし（札幌ダ1000は2走目）

項目 点数 評価理由
1.過去実績 9.5/10 前走 小倉ダ1000（2勝クラス特別）で 0.1秒差2着・上がり33.5秒はメンバー最速。着順に表れない実力＝直近1年の「勝ち馬とコンマ差の競馬」が3回＋上がり最速1回で、この12頭で最上位（コア地力8）
2.レースレベル 7.5/8 2勝クラスの特別戦（雲仙・有田・伊万里・大通公園）で常に上位争い
3.血統 2.5/3 父デクラレーションオブウォー×母父クロフネ。ダート短距離で切れを出せる配合
4.コース適性 4.3/5 札幌ダ1000で2着（2025大通公園特別）、函館ダ1000は2連勝。※同コース1走のみ＝母集団3走未満につき単独の昇格根拠にはしない（§8.8）
5.輸送適性 2/2 栗東所属だが過去に函館・札幌へ遠征して連対済み。輸送減点材料なし
6.休み明け 3/3 中29日。使い詰めでも間隔が空きすぎでもない理想値
7.脚質と展開 7.5/9 中団から。前に行きたい馬が6頭でペースが速くなる想定＝このコースが「速くなるほど後ろが届く」性質と噛み合う。前走も9番手から差して2着
8.枠順 2/3 5枠5番。外枠有利のコースで中〜外寄り、可もなく不可もなく
9.騎手 3.8/4 武豊への乗り替わり（前走は高杉）。トップジョッキーへの強化
10.調教 1.6/2 滞在／間隔の都合で直近21日の記録は0本＝欠損（評価不能）で減点しない。持ち越しの最終追い（終い1F 11.0秒＝トップ級）と、前走の「0.1秒差＋上がり最速」を状態の代替指標として高評価
11.馬体 4.5/5 538kgの大型。好走時レンジのど真ん中で連続好走中
12.厩舎 3/4 寺島良厩舎。夏の北海道シリーズに実績
合計 55.2pt S評価（本命級）

良い点
- この12頭で 地力（着順に出ない実力）が単独トップ。惜敗の中身が「速い上がりでの0.1秒差」に集中しており、力負けしていない。
- 前走の 0:56.8 は本レース想定（57.7〜58.0）を大きく上回る時計水準。
- 展開（ハイペース）が向く数少ない差し馬で、かつ 習慣後方ではなく中団（脚質消しレンズは CUT ではなく中立判定）。

不安材料
- 札幌ダ1000は前が止まらないコース。ペースが緩めば持ち味を出せずに終わる。
- 同コースの実績は1走のみ（2着）で、母集団が薄い。

期待点
- 武豊への乗り替わりで、位置取りをひとつ前に置けるなら勝ち切れる。

買い目提案

レース荒れ度＝中（実データ荒れスコア0.5／12頭立て・古馬混合）。
§8.11 に従い「◎軸＋◎不在保険を厚めに」の形にする。
券種は §8.13 の平場ルールに従い 複勝・馬連・ワイドを主役、3連複は保険と3列目確保に限定。

複勝（2点）

  • ⑫ビーマックス（○・軸の正解確認）
  • ⑩クインズシフォン（△・地力最上位クラスの中穴を馬そのもので買う）
  • ※◎⑤の複勝は配当が付かない水準のため、複勝枠は○と中穴に振り替え、◎は連系の軸として使い倒す（§8.13 D6/D17）。

ワイド（5点）★主力券種★

  • 買い方：◎軸1頭ながし
  • 軸＝⑤パールフロント
  • 相手＝⑫・①・②・⑩・⑦（印を打った5頭すべて）

馬連（4点）

  • 買い方その1：◎軸1頭ながし（2点） 軸＝⑤ → 相手 ⑫・①
  • 買い方その2：○軸1頭ながし（2点）＝◎不在保険 軸＝⑫ → 相手 ①・②

3連複（6点）

  • 買い方その1：印上位4頭ボックス（4点） — ⑤・⑫・①・②（§8.6 の「印が1-2-3着なのに0円」防止保険。4点を1〜2点に絞る変形は禁止）
  • 買い方その2：軸2頭ながし（2点） — 軸＝⑤・⑫ → 相手 ⑨・⑪（§8.8 の「当該コース母集団2走＋地力あり」の3列目保険）

合計 17点

なぜこのレースで3連複を使うか（§8.13 D14）

1000m戦で 上位4頭（⑤⑫①②）の力量差が採点上5pt以内に収まっており、着順の入れ替わりだけが読めない典型形。相手を広げる必要がなく、印上位4頭のボックスで1-2-3着の並び替えを丸ごと拾える構造になるため。加えて、当該コースで複勝率が高いのに脚質・近走で印を落とした2頭（⑨⑪）を、軸2頭ながしの3列目で最小コストで確保できる。

買い目の自己監査

  • A7（印馬の宙ぶらり禁止）: ⑤◎＝ワイド/馬連/3連複、⑫○＝複勝/ワイド/馬連×2/3連複、①▲＝ワイド/馬連×2/3連複、②△＝ワイド/馬連/3連複、⑩△＝複勝/ワイド、⑦☆＝ワイド、注⑨⑪＝3連複3列目。全頭が最低1点に入っている。
  • 単一軸依存の検算（印馬の任意1頭を着外にしても残りで最低1点当たるか）:
  • ⑤が飛ぶ → 3連複BOXの ⑫①② が生きる ✓／馬連 ⑫→①・② も生きる ✓
  • ⑫が飛ぶ → BOXの ⑤①② ✓
  • ①が飛ぶ → BOXの ⑤⑫② ✓
  • ②が飛ぶ → BOXの ⑤⑫① ✓
  • ⑩・⑦が絡む決着 → ワイド ⑤-⑩／⑤-⑦ が生きる ✓
  • ◎不在保険: 馬連⑫→①②、3連複BOX内の⑫①② の2系統を確保。
  • §8.12 適用済（3列目1点＝⑨⑪／◎抜け保険＝馬連⑫軸・BOX内⑫①②／消しの押さえ＝×を使っていないため該当なし）。
