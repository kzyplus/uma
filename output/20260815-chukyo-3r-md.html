コース特性（前残り度・ペース感受性・枠・基準時計）

中京芝1200mは前残り寄り。直近5年1,588走で3着内馬の4コーナー平均通過は5.0番手、平均16頭立てに対する位置率は0.32（0.4未満で前残り寄り）。前で運んだ馬の3着内が31.1%に対し、後方からは7.9%しかない。

今回は7頭立てなので、少頭数に絞った実測のほうが物差しとして正しい。中京芝1200・直近5年を頭数で割ると、9頭以下では3着内馬の4コーナー平均が3.83番手（10頭以上は5.21番手）と、少頭数のほうがさらに前寄りになる。

枠 — 「外枠有利」は実測に支持されない

直近5年の枠別3着内率（全体20.5%）は 3枠30.7% / 5枠28.0% / 4枠23.2% に対し、6枠14.7% / 7枠16.5% / 8枠11.4%。9頭以下に絞っても向きは変わらない（3枠62.5% / 4枠56.3% に対し 6枠12.5% / 8枠9.1%、各n=16）。よく言われる「中京芝1200は外枠有利」は長期でも少頭数でも逆を向くので書かない。

ただし今回の予想では枠を使っていない。上の母集団は平均16頭立てで7頭立て（枠＝馬番）にそのまま移せないうえ、12項目でも芝の枠順は配点0（芝は枠順を評価しないと決めてある）。

荒れ度は「やや堅い」

総称クラス名（2歳新馬）の過去平均ではなく、場×頭数×天候×距離×種別の実データで判定している。荒れスコアは-2.0で、内訳は頭数-2（10頭以下）／2歳-1／芝の短距離+1.0。→ やや堅い。

全頭がキャリア0走という前提

7頭すべてが新馬で、過去走を前提にする材料（地力・コース適性・距離適性・脚質・展開）は1つも取れない。12項目でもこれらは「データなし」として満点の分母から外し、残りの項目で按分してある。未経験は減点材料ではない。

そのため評価の物差しは次の4つに絞られる。

  1. 血統 — 父・母父の産駒が中京芝1200m前後でどれだけ走っているか（実数）
  2. 母系 — きょうだいの走暦、および母自身の競走実績
  3. 追い切り — 同じ日・同じ調教場で追われた馬の中での速さ、乗り込み本数
  4. 厩舎・騎手 — 直近90日／直近3ヶ月の成績

展開予測（脚質の機械判定にもとづくペース想定）

脚質は判定できない。脚質は通過順（4コーナー順位÷頭数）から機械判定する決まりだが、7頭すべてが新馬で通過順の実績が1つも無い。手入力のラベルは使わない決まりなので、7頭とも「不明」のまま置いてある。

そのため展開を理由にした個別の加点・減点はしていない（12項目の展開の欄も全頭「データなし」）。「前が有利なコースだからこの馬」という当てはめは、脚質が分からない以上できない。

反映したのは買い方の側だけ

  • 中京芝1200は少頭数だと4コーナー1〜4番手の3着内率が43%台に対し5番手以降が27.0%で、後方一手だけが割を食う。ただし今回はどの馬が後方に置かれるか分からない。
  • 荒れ度が「やや堅い」で7頭立てということもあり、印を5頭（頭数−2の上限ちょうど）に絞り、面を広げすぎない構成にした。
  • 3連複を組んだのは、能力の序列が実戦で一度も確かめられていないぶん3着枠が読み切れないため。7頭立てで組み合わせが限られることも理由。

当日に確認すること

  • 馬体重（発表後）。新馬なので増加は成長分としてマイナスしない。
  • パドックでの気配・入れ込み。新馬戦は当日の気配が最大の変数になるが、これはDBに無い。
